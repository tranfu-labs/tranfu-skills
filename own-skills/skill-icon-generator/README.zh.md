# Skill 图标生成

一次为一个 Skill 生成经过验证的图标包：`assets/icon.svg`、`assets/icon.png` 和对应的 `agents/openai.yaml` 元数据。

## 什么时候用它

**生成图标**

我有一个包含 `SKILL.md` 的 Skill 目录，想要一套 48×48 图标，图形表达核心任务，而不是只匹配名字里的关键词。

**替换图标**

我明确要替换已有图标，因为它重复、不清楚或语义不对，并接受生成器使用覆盖模式。

**运行自检**

我升级依赖、换机器或怀疑运行环境有问题，想确认 Sharp、Lucide 母版、品牌图形和相似度门禁都能正常工作。

**不接**

不批量重写图标，不处理非 Skill 图标、网站资产、部署工作、CI 修改或 Logo 重设计。

## 它会产出什么 / 你会看到什么

**已有图标默认受保护，除非你明确要求替换。** 生成器会停止，而不是悄悄覆盖资产。

- **图标资产**：写入 `assets/icon.svg` 和 `assets/icon.png`，并验证 PNG 确实是 48×48。
- **界面元数据**：更新 `agents/openai.yaml` 的 `icon_small` 和 `icon_large`，保留其他字段。
- **品牌处理**：品牌绑定型 Skill 使用已验证的纯品牌标志和官方主色。
- **相似度报告**：执行感知相似度门禁，确保非品牌图标之间足够可区分。
- **绝不会做**：绕过门禁、凭记忆画品牌 Logo、批量重写历史图标，或修改 CI、官网、部署配置。

## 前置条件 / 边界

**前置**

目标必须是一个 Skill 目录或 `SKILL.md`。生成器需要 Node.js，并在自身目录安装本地 Sharp 依赖。

**相邻工作**

| 需求 | 交给 |
|---|---|
| 创建或修复 Skill 内容 | Skill 创建 / 改进流程 |
| 写 README 展示文案 | `skill-readme-generation` |
| 设计产品或网站图标 | 品牌或 UI 设计流程 |

**硬边界**

- 一次只处理一个目标 Skill。
- 品牌图形必须来自注册表或可核验官方来源。
- 非品牌图标必须表达主要任务形态，并通过相似度阈值。
- 失败报告即为当前结论，直到用户选择其他图形、品牌来源或覆盖范围。
