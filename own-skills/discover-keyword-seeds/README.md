# Keyword Seed Discovery

Turn an opportunity anchor into English search probes that can later be checked in Semrush, Search Console, and search engines.

## When to use it

Use it when you have a user task, product category, competitor, website, or existing query but do not yet have a validated keyword theme.

It first identifies the user, trigger, task, desired result, current risk, and likely payer. It then generates eight keyword groups: task, product, question, price, comparison, alternative, role, and scenario terms.

## What it produces

- An opportunity-anchor restatement
- A user-task-result breakdown
- English seed keyword clusters grouped by search intent
- Exclusions and unverified assumptions
- A structured handoff for `research-keywords`

## Important boundary

The output is a set of search probes, not proof of demand. This Skill does not invent search volume, keyword difficulty, trend, revenue, or project-priority conclusions.
