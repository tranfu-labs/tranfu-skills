# 微博短帖写作

把主题、素材、长文或已有草稿写成一版可直接发布的中文微博短帖，追求传播潜力，但不牺牲事实边界。

## 什么时候用它

**直接写微博**

我有一个主题、受众、立场或几条要点，想要一条清楚、有节奏、情绪不过界的中文微博短帖。

**长文转微博**

我有完整文章，想压缩成一条微博，同时保留人物、数字、日期、引语、因果限定和原作者声音。

**润色草稿**

我已经写了一条微博，想优化开头、结构、节奏、话题标签或互动句，但不改变核心观点。

**不接**

不处理普通摘要、其他平台文案、热点调研、广告销售、文学创作、配图、发布、长微博、头条文章，也不产出需要专业审核的医疗、法律、金融结论。

## 它会产出什么 / 你会看到什么

**成功时只输出最终微博正文。** 除非你明确要求，否则不会展示计划、自检、解释、字数统计或事实声明。

- **一条成稿**：默认 200–500 个中文字符，包含真正贴合正文的话题、emoji 和互动句。
- **模式判断**：自动区分长文转微博、直接写微博和润色微博。
- **事实保护**：保留用户给出的事实，删除缺来源的精确声明，不编造出处。
- **传播检查**：交付前套用内置高传播短帖模型，修掉跑题、重复和虚假焦虑。
- **绝不会做**：自动联网、修改源文件、发布微博、虚构亲身经历，或用羞辱和夸大制造传播。

## 前置条件 / 边界

**前置**

请求目标必须是中文微博短帖，并提供主题、完整原文、要点或已有草稿之一。

**相邻工作**

| 需求 | 交给 |
|---|---|
| 当前热点长微博和配图 | `weibo-hotspot-commentary` |
| 只查热点或趋势 | 研究工作流 |
| 发布、排期或数据分析 | 社媒平台操作流程 |

**硬边界**

- 受众、模式、立场或并列焦点无法安全判断时，只问一个聚焦问题并停止。
- 时效事实需要来源；非必要的无来源精确声明会被删除。
- 用户提供的身份、引语、数字、日期和因果限定不能被改写成更强结论。
