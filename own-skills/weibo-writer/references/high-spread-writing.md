# 高传播微博短帖写作规范

本文件由《高传播观点与知识内容 AI 写作规范》（2026-07-30）提炼而来，只保留中文微博短帖需要的方法。它定义的是高传播潜力代理目标，不承诺实际流量。

## 1. 目标与边界

高传播潜力依次服务于五个行为：让目标受众愿意停下来、读完、理解并相信主要判断、记住关键表达、产生回应或分享意愿。

适用内容：观点表达、热点或现象评论、知识解释、方法论与认知内容。

禁止把传播潜力写成结果承诺。禁止为了传播牺牲准确性、逻辑和受众信任。禁止使用虚构事实、羞辱、虚假焦虑、人格攻击或夸大后果。

## 2. 五层生成模型

每次写作都在内部依次检查：

1. **观点架构**：要让哪类读者改变什么判断，哪些支撑共同完成这件事。
2. **说服论证**：读者凭什么接受判断，论证是否有效且不重复。
3. **情绪驱动**：读者从什么感受出发，读完后获得什么新状态。
4. **表达记忆**：哪些表达让观点更清楚、更容易复述，全文声音是否统一。
5. **互动传播**：正文是否自然产生一个低门槛、具体的回应入口。

短帖只强制一个核心观点、必要支撑、统一语言和有效收束。视角转换、金句、强情绪、刺痛句式和互动钩子必须逐项评估，但不适合时直接跳过。

## 3. 观点架构层

- 用一句完整陈述表达核心观点。不要用只有态度、没有判断的口号。
- 使用一至三个必要支撑，每个支撑只承担一个功能。
- 按递进、并列，或“现象 → 原因 → 影响 → 行动”组织支撑；不得重复换句话说。
- 采用视角转换时，明确旧视角、新视角和转换带来的解释价值。
- 结尾回扣核心观点，给出新的理解、判断或可执行动作；不要机械重复开头。

常见失败：观点过大、副观点互不支持、开头与正文回答不同问题、用强语气代替明确判断、压缩时删掉改变结论的限定词。

## 4. 说服论证层

根据篇幅选择足以让核心观点成立的不同功能，不机械凑数量：

| 策略 | 作用 | 使用条件 |
|---|---|---|
| 概念澄清 | 区分易混概念 | 争议来自定义混乱时 |
| 因果链 | 解释现象如何产生结果 | 能说明中间机制时 |
| 对比 | 用差异突出判断 | 两侧有可信可比依据时 |
| 具体例子 | 把抽象判断落到情境 | 来自用户素材，或明确写成假设情境时 |
| 类比 | 用熟悉结构解释陌生概念 | 对应关系准确时 |
| 回应反方 | 承认合理异议并说明边界 | 主题存在明显反对意见时 |
| 事实或数据 | 支撑判断 | 素材可靠且不虚构出处时 |
| 实践推演 | 推出判断或行动影响 | 推演完整且不把可能写成必然时 |

不要把两个相似例子当成两种论证。不要把时间先后写成因果。行动建议必须能从核心观点推导出来。

## 5. 情绪驱动层

1. 判断受众阅读前的主要状态，例如困惑、焦虑、怀疑、疲惫或好奇。
2. 确定读完后的目标状态，例如被理解、获得清晰感、恢复掌控感、形成判断或愿意行动。
3. 选择低、中或高强度；理性和技术主题默认低至中强度。
4. 选择一条情感曲线，让转折由观点和论证推动，而不是靠形容词推动。
5. 删除只负责刺激、不能推进理解的句子。

可用曲线：

- 好奇 → 发现问题 → 看懂机制 → 获得清晰感
- 不适 → 被准确命名 → 视角反转 → 获得掌控感
- 怀疑 → 看见依据 → 修正判断 → 形成确信
- 共鸣 → 看见深层原因 → 被理解 → 愿意表达

只有正文能解释表层感受与深层需要的联系时，才使用深层情绪。不得替受众虚构创伤、身份或生活经历。

刺痛表达只能指出行为或机制造成的隐性代价，且正文必须已有论证，后文必须提供新的理解、选择或行动出口。不得连续使用多个刺痛句式。

## 6. 表达记忆层

- 使用清晰、直接、口语自然的中文。
- 保持信息密度，每句话只承担一个主要意思。
- 用具体名词和动作替代空泛抽象词。
- 让段落之间有推进关系，语气坚定但保留必要边界。
- 禁止机械排比、空泛鼓励、伪深刻反转、过量感叹号和 AI 套话。

金句只能压缩正文已经论证过的判断。它可以概括核心观点、表达关键对比、命名模糊感受或压缩复杂机制；不能突然引入新结论。没有自然形成的金句时直接跳过。

## 7. 互动传播层

互动必须由正文自然导出，只使用一个入口：

- **提问**：问读者能凭真实经验回答的具体问题。
- **填空**：留下能映射真实处境的空位，不强迫接受作者结论。
- **争议**：呈现两个都有合理依据的立场，邀请选择或补充。

禁止使用无焦点的“你怎么看”、多个连续问题、虚假二选一、给反方贴标签，或用“评论区告诉我”代替问题本身。主题不适合互动时直接跳过。

## 8. 动态模块选择

对视角转换、金句、情绪价值句式、刺痛句式和互动钩子逐项判断：

- 能推进理解、说服或记忆 → 使用。
- 只增加刺激或形式感 → 跳过。
- 与正文无关或缺少论证支撑 → 禁止使用。
- 因篇幅不足与核心论证冲突 → 优先保留核心观点和必要支撑。

不得为了覆盖公式强行煽情、制造虚假冲突、堆砌金句或追加无关问题。

## 9. 内部硬门槛

交付前逐项检查，失败时先改稿，不把检查结果输出给用户：

1. 核心观点能用一句话准确表达。
2. 每个支撑都直接服务核心观点，没有重复或跑题。
3. 论证足以支持观点，不存在明显逻辑跳步或自相矛盾。
4. 没有虚构亲身经历、来源、机构、研究、引语、链接或精确出处，也没有把假设推演写成已发生案例。
5. 没有使用羞辱、虚假焦虑、人格攻击或夸大后果。
6. 金句来自正文已完成的论证，没有引入新结论。
7. 刺痛表达指向行为或机制，并提供理解或行动出口。
8. 互动钩子与正文直接相关；不适合时已经跳过。
9. 语言适合目标受众，全文声音一致。
10. 内容只能声称具有高传播潜力，不能承诺成为爆款。
