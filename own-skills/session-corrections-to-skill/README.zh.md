# session-corrections-to-skill 会话修正沉淀

把会话中的纠正变成对应 skill 里的持久知识。纠正来源有两种：用户明确否定了 agent 的既有行为；或现实结果否定了原做法，并且根因和正确做法已经得到验证。

一次性范围要求、多个可行方案中的当次选择、针对 agent 的通用工作偏好，以及尚未解决的问题都不沉淀。每条有效纠正都要用目标 skill 的 `description` 核对职责范围，不能硬塞进主题最接近的 skill。

## 沉淀内容

一条纠正可以产出以下一种或多种内容：

- 定义：`名字 + 要求`
- 实施细则：`场景 + 操作`
- 错误案例：`场景 + 错误`

任何文件修改前，先向用户展示拟写内容。只写入用户确认的内容：优先复用目标 SKILL 中的同类表格，没有时创建最小两列表；不借机重构或扩写目标 skill。

## 什么时候用

- 会话中纠正了某个 skill 的行为，想让这项纠正持续生效
- 会话中踩了坑，并且根因和正确做法已经得到验证

## 你会得到什么

- 写入对应 SKILL 的已确认定义、实施细则或错误案例
- 一份不沉淀的一次性、通用或未解决事项清单
- 一份附推荐名称的「需新增 skill」清单
- 一份从原始纠正到实际写入内容的对账单
