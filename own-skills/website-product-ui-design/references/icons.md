# 图标系统规范

本文件负责功能图标的来源选择、风格锁定、语义映射、尺寸、回退与验证。品牌 Logo 和第三方服务标志不属于功能图标，只能使用项目或权利方提供的正式资源。

## 唯一主图标系统

按以下顺序确定当前产品区域的唯一主图标系统：

1. 项目已有 Icon Registry、图标包装组件或设计系统图标入口。
2. 项目文档明确指定的图标库与变体。
3. 当前产品区域占主导的图标库、风格和导入方式。
4. 与目标最接近的同类组件所用图标系统。
5. 项目没有图标系统且用户已授权新增依赖时，使用 Reicon。

两个同等权威来源冲突时报告 `reference_conflict`，不得自行混用。主图标系统确定后，本次新增或修改的功能图标只能来自该系统；不得因为某个图标难找而引入第二套库。

若项目没有图标系统且未获新增依赖授权，继续使用用户提供或项目已批准的本地图标资产；仍无法完成时报告 `missing_required_dependency` 或 `missing_required_asset`。

## Reicon 默认配置

Reicon 只在项目没有既有图标系统且新增依赖已获授权时作为默认库：

- 官方图标目录：<https://reicon.dev/icons>
- 官方文档与包名以 Reicon 当前站点及目标项目实际安装版本为准，不从记忆或第三方转载推断。

- 默认使用 `Outline`，保持库的默认 1.5px 描边。
- `Filled` 只用于同一个语义图标的明确选中、激活或强调状态，不用于随机替换普通图标。
- 视觉属性继承项目现有样式，不由本 Skill 指定新配色。
- 控件内尺寸使用 `tokens.md` 的“控件与图标匹配”；无上下文时使用 `control-default` 对应尺寸。
- 优先使用项目构建系统对应的正式包并按需导入；CDN 仅用于明确的静态页面或原型任务，且必须锁定具体版本，禁止使用 `@latest`。
- Reicon MCP 已可用时可用于搜索、预览和生成候选；否则查阅官方名称目录或检查当前安装包导出。不得为了查图标自动安装 MCP。
- 写入代码前验证当前安装版本、正确包名、精确导出名、属性名和构建兼容性。

## 语义图标注册表

优先复用项目已有注册表或包装入口。没有注册表且任务会新增多个图标或重复语义时，为受影响产品区域建立一个共享入口，并记录：

- 稳定语义键，例如 `icon.navigation.home`、`icon.action.add`、`icon.action.close`、`icon.status.success`。
- 主图标库中的精确导出名与来源包。
- 允许的 Outline/Filled 状态关系。
- 适用的尺寸角色与使用场景。

新建或改动的业务组件只从该共享入口导入语义别名，不直接从底层图标包导入。同一语义只暴露一个默认图形；`house2`、`house3` 等候选变体不能作为新的业务别名绕过既有映射。

以下图形家族必须成套选择，不得逐个混搭：

- 方向箭头、返回与前进；
- Chevron、展开与收起；
- 添加、减少、关闭与确认；
- 成功、警告、错误与信息状态；
- 文件、文件夹及其状态变体；
- 播放、暂停、停止与跳转。

## 尺寸与光学一致性

- 控件内图标严格使用 `tokens.md`“控件与图标匹配”表，不在本文件重复维护映射值。
- 非控件内的辅助图标使用 16px，常规导航或功能入口使用 20px，重要状态或移动操作使用 24px，独立展示图标从 32px 开始。
- 同一行、工具栏、导航或同级卡片中的功能图标使用相同名义尺寸和固定尺寸容器。
- 主次按钮不通过图标大小区分优先级；图标大小与点击热区分开处理。
- 不为单个显得偏小的图标私自缩放。若统一尺寸下视觉重量明显异常，改选同库同家族候选并更新注册表。

## 缺失图标回退

依次执行：

1. 在主图标系统内寻找语义等价且同家族的候选。
2. 复用项目已批准、风格匹配并纳入注册表的本地图标资产。
3. 非必要图标改用清晰文字标签。
4. 关键语义无法保持时报告 `missing_required_asset`。

不得静默切换其他功能图标库，也不得用 Emoji、任意字符、临时绘制或未经验证的内联 SVG 代替。

## 验证

- 静态检查：确认依赖真实存在、导出名有效、同一产品区域没有未经允许的第二图标库导入。
- 语义检查：确认图形含义与上下文一致，同一语义没有多个默认映射。
- 视觉检查：按本文件定义的尺寸角色和适用状态检查风格、笔画、光学重量、对齐与裁切。
- 状态检查：Outline/Filled 切换不改变图标边界、对齐或布局。
- 可访问性：装饰图标对辅助技术隐藏；纯图标按钮提供 accessible name；状态图标配合文字、位置或其他非颜色信号。
