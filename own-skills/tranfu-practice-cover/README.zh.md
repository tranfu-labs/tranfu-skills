# TranFu 实践封面

为 TranFu `/practice` 文章创建可版本化的 16:9 封面：左侧标题清晰，右侧主题物紧凑，风格稳定可验收。

## 什么时候用它

**生成实践封面**

我有一篇 TranFu 实践文章的标题和主题，想生成一张左侧标题、右侧主题物的文章封面。

**重做封面**

我已有封面版本，但想按新标题、新主题或参考图重新生成，同时保留技术词拼写和大小写。

**检查封面**

我想确认封面是否符合本地红白玻璃风格、留白比例、缩略图可读性和标题安全区。

**不接**

不处理实践页首屏大图、非 TranFu 通用文章封面、Logo、图标集、海报、幻灯片封面、整页 UI 设计或与实践封面无关的纯修图。

## 它会产出什么 / 你会看到什么

**图片模型只生成无文字背景，标题由确定性排版工具渲染。** 这能避免技术词在图里被画错。

- **无文字背景**：右侧是紧凑主题物，左侧保留标题区，不出现伪文字、Logo 或水印。
- **标题排版**：用 MiSans 渲染标题，保护 `AGENTS.md`、`Git Worktree` 等技术词。
- **版本文件**：导出版本化 PNG、布局说明和优化 JPG，不覆盖旧资产。
- **页面集成**：只有用户明确要求时，才更新目标页面并做集成验证。
- **绝不会做**：把失败背景靠裁剪遮住、让图片模型直接写标题、复制参考图里的具体主题符号。

## 前置条件 / 边界

**前置**

需要完整文章标题、文章主题或摘要、输出目录；生成新背景需要运行时具备图片生成能力，最终标题需要已安装标题渲染能力。

**相邻工作**

| 需求 | 交给 |
|---|---|
| TranFu 页面 UI 或组件设计 | `tranfu-website-design` |
| 通用文章封面 | 通用封面生成流程 |
| Logo 或图标集 | 图标 / 品牌资产流程 |

**硬边界**

- 标题或主题缺失时先问缺失项，不生成占位封面。
- 现有资产永不覆盖，必须选择下一个版本号。
- 背景不合格就重新生成，不能用标题块或裁剪掩盖问题。
