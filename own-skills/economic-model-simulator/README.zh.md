# 经济模型模拟器

创建或修改交互式页面，解释钱流向哪里、资产归谁，以及分配和复投如何改变用户的资产状态。

## 准备材料

提供经济规则、投入金额、分配比例、资产归属和用户可选路径。修改已有模拟器时，附上代码或页面要求，并区分已核实参数和模拟假设。

## 使用方式

请 Agent 使用 `$economic-model-simulator` 处理材料。Skill 将页面组织为四个联动模块：资金流向图、账户日志、用户路线图、模拟假设及相关说明。切换路径时，图、日志和结果同步更新。

Agent 会核对分配计算、选项兼容关系、分支切换、节点和边的激活范围，以及复投资金的返回位置。交付包括页面或代码、验证结果和未验证项。

## 适用边界

这是页面实现规范，不包含独立应用。不用于判断投资价值或验证项目经济机制。业务规则和参数来自当前任务，SKILL.md 中的加盟店案例是假设示例。
