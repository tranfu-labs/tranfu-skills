# 定义

| 名字 | 要求 |
| --- | --- |
| 页面 frame | MUST 用一个外围矩形作为页面边框；MUST 用一个 frame 包裹页面及其产品标注，并将页面名字作为该 frame 的文字；页面注释 MUST 位于页面边框外、该 frame 内。 |
| 产品标注 | 位于页面边框外、页面 frame 内，用于解释模块职责、状态边界、业务规则与恢复路径的结构化注释。 |
| 产品标注卡 | 由语义色边框、同色编号角标、黑色标题和灰色描述组成的结构化页面注释。 |

# 实施细则

| 场景 | 操作 |
| --- | --- |
| 页面跳转 | MUST 用从真实操作点指向目标页面的实线箭头直接表达；跨画布或首尾闭环时用长回程实线箭头。NEVER 另写说明段或重复流程图，除非用户明确指定。 |
| 产品标注 | MUST 将产品标注页面的标题写在页面矩形外。 |
| 产品标注 |  MUST 呈现形式采用标注卡 |
| 产品标注卡 |  一种左右布局的结构化页面注释。左侧为语义色编号角标，右侧为纵向排列的黑色标题与灰色描述；卡片使用同语义色边框。 |

# 场景错误

| 场景 | 错误 |
| --- | --- |
| 页面 frame | 没有完全包裹所有的内容 |
| 页面 frame | frame 之间的间距过于拥挤 |
