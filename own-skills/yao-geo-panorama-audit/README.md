# Yao GEO Panorama Audit

Build an evidence-led GEO baseline from a brand's official website and public sources. The skill turns that evidence into a complete diagnosis, a question-coverage matrix, and prioritized onsite and offsite opportunity maps.

## When to use it

Use it for project kickoff, quarterly review, competitor catch-up, or pre-campaign assessment when the team needs a broad GEO diagnosis rather than a single-page review.

## What it produces

- Official-site crawl and claim-level evidence ledger
- Brand, product, content, technical, Schema, competitor, and external-source diagnosis
- User-question coverage matrix across nine decision intents
- GEO quality scores with assumptions and verification status
- P0/P1 onsite and offsite opportunity maps with owners and acceptance criteria
- Markdown, HTML, Word, and PDF report artifacts

## Boundaries

This skill does not sample answer platforms, diagnose only one URL, write standalone articles or titles, build attribution dashboards, or turn an existing diagnosis into a 30/60/90-day execution plan.

Brand claims, customer cases, pricing, credentials, and performance statements must have supporting sources. Unverified claims remain explicitly marked for confirmation.
