# Yao GEO 全景诊断

从品牌官网与公开信源建立证据账本，再形成完整 GEO 基线、用户问题覆盖矩阵，以及有优先级的站内和站外机会地图。

## 什么时候使用

适合项目启动、季度复盘、竞品追赶和投放前评估。目标是做系统级 GEO 诊断，而不是只检查一个页面。

## 会产出什么

- 官网抓取清单与断言级证据账本
- 品牌实体、产品、内容、技术、Schema、竞品和外部信源诊断
- 覆盖九类决策意图的用户问题矩阵
- 带假设和核验状态的 GEO 质量评分
- 包含负责人和验收口径的 P0/P1 站内、站外机会地图
- Markdown、HTML、Word、PDF 四格式报告

## 边界

本 skill 不做问答平台采样、单 URL 诊断、单篇文章或标题写作、归因看板设计，也不把已有诊断拆成 30/60/90 天执行计划。

品牌断言、客户案例、价格、资质与效果数据必须有来源；无法核验的内容明确标记为待确认。
