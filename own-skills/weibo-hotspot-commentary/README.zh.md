# 微博热点评论

把热点、固定主题或具体事件写成有证据的微博长文，并把文稿、图片和出处一次性交付。

## 什么时候用它

**当前热点**

我想从当前微博热榜里挑一个适合评论的事件，不只是复述新闻，而是解释它为什么重要、和 AI 有什么具体关系、普通读者能从中看到什么。

**固定主题**

我已经有一个方向，比如企业 AI 落地、AI 内容工具或行业变化，想让 skill 先找到近期可核验的事件，再写成有时效的微博长文。

**具体事件**

我手上已经有一个新闻、发布、人物动作或社会话题，想把它核验清楚后，写成一篇观点明确、分析完整、带配图的微博长文。

**不接**

不是写微博短句、其他平台文案、只查热点、只做公司调研、只发布或排期，也不是做数据分析。它只读公开资料，不登录、不发布微博。

## 它会产出什么 / 你会看到什么

**它不会在中途零散交付草稿或单张图，而是在全部检查完成后统一交付完整包。**

- **热点证据**：判断请求属于当前热榜、固定事件还是固定主题，保存公开来源、核验结论和拒绝理由。
- **AI 评论角度**：把事件推导成具体的 AI 分析问题，覆盖机制、影响、判断和边界，不写空泛趋势话术。
- **可选公司证据**：默认公司是望船夫 TranFu，但只有公开证据支持且确实有帮助时才写入产品内容。
- **微博长文**：生成 1500-2000 字长文，再改写成通俗表达，并校验热点分析占比高于单纯事件复述。
- **配图**：先找有复用依据的公开图片，再在文稿冻结后生成缺少的图片。
- **统一交付**：把通过检查的文稿、图片、出处说明和清单放进 `final-delivery/`。
- **绝不会做**：编造事实、读取私有系统、绕过登录限制、发布微博、排期投放或修改外部内容。

## 前置条件 / 边界

**前置**

运行环境需要可用的内容生成与图片工具、公开网页搜索能力，并能读取本 skill 的 `references/provider-contracts.md`、`references/delivery-contract.md` 与 `scripts/` 下的校验和打包脚本。

**相邻工作分工**

| 需求 | 交给 |
|---|---|
| 只写一条短微博或社媒短文 | 更短的社媒文案 skill |
| 只查看当前热点 | 热点发现或研究工具 |
| 只做公司调研 | 市场研究或公司画像流程 |
| 发布、排期、看数据 | 社交平台操作流程 |

**硬边界**

- 只使用公开来源；无法核验的事件、消费受害者的灾难、隐私暴露、纯娱乐八卦和高伤害争议都会被拒绝。
- 产品露出是可选项，而且必须有公开证据；证据不足时，全文只评论热点及其 AI 含义。
- 固定事件和固定主题不要求进入微博热榜前 50，但仍必须有近期、可核验的公开证据。

**微妙边界**

- 只说「写微博」且没有给主题 → 走当前热榜发现，并默认使用 TranFu 作为可选公司背景。
- 给出长期方向 → 走固定主题，先查 7 天内事件，必要时扩展到 30 天。
- 给出一个具体事件 → 走固定事件核验，不扫描热榜前 50。
