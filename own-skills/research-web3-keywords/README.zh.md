# Web3 关键词调研

把英文种子词或现成关键词主题转换为可复核的搜索、竞品、收费和收入证据。

## 什么时候使用

通常在种子词发现之后使用，也可以直接从现成关键词、竞品、网站或 Search Console 查询开始。

它会按用户问题聚类关键词，核对直接搜索证据，调查解决同一问题的产品和付费信号，并整理成关键词调研表可用的结构化记录。

## 判断底线

只有关键词证据强，并且收入与付费证据为强或中时，才能创建一条“待评审”候选项目。

关键词证据至少需要一项可复核的直接来源：Semrush 最近完整月数据，或 Search Console 真实查询数据。收费页、企业案例、监管要求、融资、TVL 和竞品数量都不能替代关键词证据。

## 会产出什么

- 关键词主题及代表词
- 带来源、市场、月份和查询日期的搜索证据
- 直接竞品、收费、付费和收入证据
- 优先、进入验证、继续观察或淘汰的四分支结论
- 可录入 Lark 的字段，以及符合条件时的待评审候选项目记录

## 重要边界

本 Skill 不批准最终立项。拿不到的私有数据留空或标记待核实，公开价格不能写成已经确认的真实收入。
