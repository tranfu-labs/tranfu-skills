# Web3 Keyword Research

Turn English seed keywords or an existing keyword theme into reviewable search, competitor, pricing, and revenue evidence.

## When to use it

Use it after seed discovery, or start directly from an existing keyword, competitor, website, or Search Console query.

The Skill groups terms by the user problem they solve, checks direct search evidence, reviews matching products and payment signals, and prepares structured records for the keyword research table.

## Decision rule

A keyword theme can create a pending-review candidate project only when direct keyword evidence is strong and payment evidence is strong or medium.

At least one verifiable direct search source is required: recent Semrush data or real Search Console query data. Pricing pages, enterprise cases, regulatory requirements, funding, TVL, and competitor counts cannot replace keyword evidence.

## What it produces

- Keyword themes and representative terms
- Search evidence with source, market, month, and query date
- Direct competitors, pricing, payment, and revenue evidence
- A four-branch result: priority, validate, observe, or eliminate
- Lark-ready research fields and, only when qualified, a pending-review candidate record

## Important boundary

It never approves final project initiation. Missing private data remains blank or unverified, and public pricing is never reported as confirmed revenue.
