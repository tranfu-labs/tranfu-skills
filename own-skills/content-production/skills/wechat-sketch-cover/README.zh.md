# 微信手绘封面

根据准确标题或 Markdown 文章生成一张固定风格的微信封面图。

## 什么时候用它

**标题封面**

我有准确中文或中英混合标题，想生成一张匹配标题的公众号封面。

**文章封面**

我提供 Markdown 文章时，想让它提炼一个固定暖色手绘笔记风概念。

**固定风格**

输出必须是微信公众号使用的 1923x818 PNG 时，它负责规范尺寸。

**不接**

通用封面、其他平台、封面点评、设计建议、只要提示词、正文配图、其他风格、品牌叠加、修图、链接读取和发布都不交给它。

## 它会产出什么 / 你会看到什么

**它只交付本地结果，不负责平台发布，也不会替用户做额外授权。**

- **封面 PNG**: 写入一张规范为 1923x818 的 PNG 候选。
- **提示词与检查**: 提炼概念、组装提示词、评估候选并记录入选结果。
- **不发布**: 只生成本地资产，不上传到微信。
- **绝不会做**: 不合并工作流阶段、不发布内容、不伪造缺失的用户确认。

## 前置条件 / 边界

**前置**

需要提供准确中文或中英混合标题，或一篇可读取的 Markdown 文章；运行环境需要可用的生图路径。

**相邻 skill 分工**

| 动作 | 交给 |
|---|---|
| 正文配图 | **post-illustration-images** |
| 压缩封面 | **compress-image** |
| 文章排版 | **format-content** |

**不接的场景**

- 明确属于其他 skill 的请求，应交给对应 skill。
- 输入缺失或不可读取时，应停止并说明，不凭空补内容。
- 平台发布、账号登录、排期和发布后数据分析都不属于它。

**微妙边界**

- 完整内容生产流程可以把它当作 provider 调用，但它仍然只负责自己的契约产物。
- 独立使用时不应改动无关项目文件，只报告实际产出的文件或检查结果。
