# 中文内容审校

审校已完成的中文平台稿，同时保护标题、论点、事实、立场和结构。

## 什么时候用它

**排版前审校**

终稿准备进入排版或交接发布前，我想做最后的语言和一致性检查。

**自然声口**

稿子有 AI 味时，我想让表达更自然，但不改变事实和论点。

**三轮审校**

我明确需要完整审校流程时，它按内容、声口和细节顺序处理。

**不接**

从零写作、选题、大纲、翻译、只排版、学术法律公文、发布和规避检测都不交给它。

## 它会产出什么 / 你会看到什么

**它只交付本地结果，不负责平台发布，也不会替用户做额外授权。**

- **干净终稿**: 返回可进入排版的审校稿。
- **回归检查**: 保护论点、立场、事实、数据、案例和结构。
- **克制修改**: 改善措辞和阅读节奏，不新增实质内容。
- **绝不会做**: 不合并工作流阶段、不发布内容、不伪造缺失的用户确认。

## 前置条件 / 边界

**前置**

需要提供面向支持平台的完整简体中文稿。未成稿的想法和素材应先交给上游写作流程。

**相邻 skill 分工**

| 动作 | 交给 |
|---|---|
| 撰写正文 | **draft-content** |
| 生成标题 | **title-options** |
| 微信排版 | **format-content** |

**不接的场景**

- 明确属于其他 skill 的请求，应交给对应 skill。
- 输入缺失或不可读取时，应停止并说明，不凭空补内容。
- 平台发布、账号登录、排期和发布后数据分析都不属于它。

**微妙边界**

- 完整内容生产流程可以把它当作 provider 调用，但它仍然只负责自己的契约产物。
- 独立使用时不应改动无关项目文件，只报告实际产出的文件或检查结果。
