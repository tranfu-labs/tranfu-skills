# 文章标题生成

基于成稿生成不夸大承诺的平台标题，避免新增原文没有的信息。

## 什么时候用它

**标题候选**

我有完整文章或较完整片段，想拿到几组能兑现正文内容的标题。

**优化标题**

已有旧标题时，我想结合正文优化，而不是凭感觉重写。

**平台标题**

不同平台需要不同标题风格时，我想适配表达，但不新增事实。

**不接**

选题、正文写作、封面、开头、网页标题、落地页、广告、邮件主题、命名，以及 URL、DOCX、PDF、TXT 输入都不交给它。

## 它会产出什么 / 你会看到什么

**它只交付本地结果，不负责平台发布，也不会替用户做额外授权。**

- **标题池**: 返回带平台意识的文章标题候选。
- **承诺校验**: 拒绝新增原文没有的时间、数字、权威、引语、因果、冲突或结果。
- **选择辅助**: 帮助比较候选，但不偏离正文。
- **绝不会做**: 不合并工作流阶段、不发布内容、不伪造缺失的用户确认。

## 前置条件 / 边界

**前置**

需要提供已完成文章、片段，或旧标题加正文。输入应是可读文本，不是远程链接或办公文档。

**相邻 skill 分工**

| 动作 | 交给 |
|---|---|
| 选择选题 | **content-topics** |
| 撰写正文 | **draft-content** |
| 审校正文 | **proofread-content** |

**不接的场景**

- 明确属于其他 skill 的请求，应交给对应 skill。
- 输入缺失或不可读取时，应停止并说明，不凭空补内容。
- 平台发布、账号登录、排期和发布后数据分析都不属于它。

**微妙边界**

- 完整内容生产流程可以把它当作 provider 调用，但它仍然只负责自己的契约产物。
- 独立使用时不应改动无关项目文件，只报告实际产出的文件或检查结果。
