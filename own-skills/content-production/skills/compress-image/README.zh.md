# 图片压缩

在支持的本地图片格式内减小文件体积，不处理额外编辑需求。

## 什么时候用它

**压缩 PNG**

我有 PNG、JPEG 或 WebP 文件，需要生成更小的交付版本。

**优化图片**

文章配图体积太大时，我想减小文件大小，但不改尺寸、不裁剪、不修图。

**转 WebP**

支持的图片需要转成 WebP 或无损 PNG 时，我想要本地输出并完成检查。

**不接**

动图、远程链接、改尺寸、裁剪、修图和不支持的格式都不交给它。

## 它会产出什么 / 你会看到什么

**它只交付本地结果，不负责平台发布，也不会替用户做额外授权。**

- **压缩文件**: 写入本地 WebP 或无损 PNG 候选文件。
- **结果校验**: 检查输入格式是否支持，并确认输出可用。
- **不做设计**: 不会裁剪、缩放、修图或做创意改动。
- **绝不会做**: 不合并工作流阶段、不发布内容、不伪造缺失的用户确认。

## 前置条件 / 边界

**前置**

需要提供可读取的本地 PNG、JPEG 或 WebP 文件；运行环境需要可用的图片压缩依赖。

**相邻 skill 分工**

| 动作 | 交给 |
|---|---|
| 生成文章配图 | **post-illustration-images** |
| 生成微信封面 | **wechat-sketch-cover** |
| 完整内容打包 | **content-production** |

**不接的场景**

- 明确属于其他 skill 的请求，应交给对应 skill。
- 输入缺失或不可读取时，应停止并说明，不凭空补内容。
- 平台发布、账号登录、排期和发布后数据分析都不属于它。

**微妙边界**

- 完整内容生产流程可以把它当作 provider 调用，但它仍然只负责自己的契约产物。
- 独立使用时不应改动无关项目文件，只报告实际产出的文件或检查结果。
