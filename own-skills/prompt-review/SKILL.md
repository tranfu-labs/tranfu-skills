# 提示词审查

只检查硬强调词：找出 `MUST`、`MUST NOT`、`NEVER`、`ALWAYS`、`CRITICAL`、
`REQUIRED`、“必须”、“绝不”、“永远”、“始终”、“务必”、“严禁”等用词，
在不改变原意的前提下，给出普通、直接的替换措辞。
