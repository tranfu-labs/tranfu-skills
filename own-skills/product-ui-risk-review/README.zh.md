# 产品 UI 风险审查

`product-ui-risk-review` 用来审查用户误解后可能造成高成本或难恢复后果的产品 UI 流程。它重点检查用户决策清晰度、状态覆盖、确认设计、错误恢复、风险文案和上线准备度。

它适用于资产、账户、授权、签名确认、交易提交、支付、转账、异步结果和跨系统流转等流程。对外是通用 UI 风险方案，但内核重点覆盖资产、授权、交易类产品场景。

## 主要检查什么

- 用户操作前是否看清对象、范围、金额、目标、成本和后果。
- 授权、签名确认和正式提交是否在不同用户决策时拆开。
- 加载中、数据不完整、权限不足、用户取消、处理中、成功、失败、超时和部分成功状态是否可恢复。
- 高风险按钮是否使用具体动作文案，而不是只写 `Confirm`、`Submit`、`OK` 或「继续」。
- 静态审查和真实运行验证是否分清楚。

## 常用提示

```text
使用 $product-ui-risk-review 审查这个支付流程的上线风险。
使用 $product-ui-risk-review 按产品 UI 要求完善这个资产兑换页面。
使用 $product-ui-risk-review 审查这个授权确认流程有没有高风险问题。
```

## 边界

这个 skill 不输出法律合规结论、投资建议、底层安全审计结果、品牌设计或纯视觉审美意见。它只审查并完善用户操作相关的产品 UI 风险。
